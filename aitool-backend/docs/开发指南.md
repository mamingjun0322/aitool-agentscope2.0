## 一、项目概览

本项目是一个基于 **AgentScope Java 2.0** 框架 + **Spring Boot 3.3** + **Electron** 的 AI 智能体应用。

``
aitool/
+-- aitool-backend/          # Java 后端（智能体核心）
|   +-- src/main/java/       # 业务代码（仅 3 个类）
|   +-- src/main/resources/  # 配置文件
|   +-- .agentscope/         # 运行时数据（会话、工作区）
+-- aitool-electron/         # Electron 前端（聊天 UI）
+-- 框架源码/                # AgentScope Java 框架源码
``

后端仅包含 3 个 Java 类：

| 类名 | 职责 |
|------|------|
| `AgentScopeJavaApplication.java` | Spring Boot 启动入口 |
| `ChatController.java` | 核心控制器：Agent 构建 + REST API |
| `CorsConfig.java` | 跨域配置 |

``yaml

  application:
    name: AgentScope_java
  webflux:
    base-path: /

server:
  port: 8088

agent:
  # ===== LLM 模型配置 =====
  model:
    base-url: http://10.26.46.17:6007    # 模型 API 地址（兼容 OpenAI 协议）
    api-key: YOUR_API_KEY                 # API 密钥
    name: Qwen3.5-122B-A10B-GPTQ-Int4    # 模型名称

  # ===== 系统提示词 =====
  sys-prompt: "你是一个智能问答助手，帮助用户解答各类问题。请用中文回答。"

  # ===== 推理控制 =====
  max-iters: 10              # 单次对话最大推理-行动循环次数

  # ===== 工作区 =====
  workspace: .agentscope/workspace   # Agent 文件读写根目录

  # ===== 上下文压缩配置 =====
  compaction:
    trigger-tokens: 40000           # Token 数达到此阈值时触发压缩
    keep-tokens: 8000               # 压缩后保留最近 N 个 token
    trigger-messages: 80            # 消息数达到此阈值时触发压缩
    keep-messages: 30               # 压缩后保留最近 N 条原始消息
    flush-before-compact: true      # 压缩前先将重要信息写入长期记忆
    offload-before-compact: true    # 压缩前将原始日志卸载到文件
    truncate-args-max-length: 2000  # 工具调用参数截断到 2K

  # ===== 大工具结果卸载 =====
  tool-result-eviction:
    max-size: 50000                 # 超过 50K 字符的结果卸载到文件

  # ===== 长期记忆 =====
  memory:
    async-flush: true               # 异步刷新记忆

  # ===== RAG 知识库 =====
  rag:
    api-key: YOUR_DASHSCOPE_KEY     # DashScope API Key
    model-name: text-embedding-v3   # Embedding 模型
    dimensions: 1024                # 向量维度

  # ===== Git 技能仓库 =====
  skill:
    git-url: https://github.com/your-org/skills.git
    branch: main

  # ===== MySQL 会话存储 =====
  mysql:
    jdbc-url: jdbc:mysql://localhost:3306/agentscope?serverTimezone=UTC&useSSL=false&allowPublicKeyRetrieval=true
    username: root
    password: root
    database-name: agentscope
    table-name: agentscope_sessions
    create-if-not-exist: true
``

| 配置项 | 默认值 | 说明 |
|--------|--------|------|

## 六、第 3 步：构建 HTTP 传输层

HTTP 传输层负责与 LLM API 通信。强制使用 HTTP/1.1 避免 vLLM 等服务的兼容性问题：

``java
import io.agentscope.core.model.transport.HttpTransportConfig;
import io.agentscope.core.model.transport.HttpVersion;
import io.agentscope.core.model.transport.JdkHttpTransport;

JdkHttpTransport httpTransport = JdkHttpTransport.builder()
        .config(HttpTransportConfig.builder()
                .httpVersion(HttpVersion.HTTP_1_1)   // 强制 HTTP/1.1
                .build())
        .build();
``

> **为什么用 HTTP/1.1？** 部分本地部署的模型服务（如 vLLM）不支持 HTTP/2，使用 HTTP/1.1 可避免 400 错误。

## 八、第 5 步：初始化会话状态存储

会话状态存储负责持久化对话上下文，支持跨请求恢复。

### 方案 A：MySQL（生产推荐）

``java
import com.zaxxer.hikari.HikariDataSource;
import io.agentscope.extensions.mysql.state.MysqlAgentStateStore;

HikariDataSource ds = new HikariDataSource();
ds.setJdbcUrl("jdbc:mysql://localhost:3306/agentscope");
ds.setUsername("root");
ds.setPassword("root");

AgentStateStore stateStore = new MysqlAgentStateStore(
        ds, "agentscope", "agentscope_sessions", true);
``

### 方案 B：JSON 文件（开发调试）

``java
import io.agentscope.core.state.JsonFileAgentStateStore;

AgentStateStore stateStore = new JsonFileAgentStateStore(
        Paths.get(".agentscope/sessions"));
``

### 方案 C：内存（测试用）

``java
import io.agentscope.core.state.InMemoryAgentStateStore;

AgentStateStore stateStore = new InMemoryAgentStateStore();
``

### 对比

| 方案 | 持久化 | 多节点 | 适用场景 |
|------|--------|--------|----------|
| MySQL | 是 | 支持 | 生产环境 |
| JSON 文件 | 是 | 不支持 | 本地开发 |
| 内存 | 否 | 不支持 | 单元测试 |

## 九、第 6 步：构建 RAG 知识库（可选）

RAG（检索增强生成）让 Agent 能够基于私有知识库回答问题。

``java
import io.agentscope.core.embedding.EmbeddingModel;
import io.agentscope.core.embedding.dashscope.DashScopeTextEmbedding;
import io.agentscope.core.rag.KnowledgeRetrievalTools;
import io.agentscope.core.rag.knowledge.SimpleKnowledge;
import io.agentscope.core.rag.store.InMemoryStore;

// 1. Embedding 模型
EmbeddingModel embeddings = DashScopeTextEmbedding.builder()
        .apiKey("YOUR_DASHSCOPE_KEY")
        .modelName("text-embedding-v3")
        .dimensions(1024)
        .build();

// 2. 向量存储（开发用内存版，生产可换 PgVectorStore / MilvusStore）
InMemoryStore store = InMemoryStore.builder().dimensions(1024).build();

// 3. 组装 Knowledge
SimpleKnowledge knowledge = SimpleKnowledge.builder()
        .embeddingModel(embeddings)
        .embeddingStore(store)
        .build();

// 4. 包装成工具
KnowledgeRetrievalTools ragTools = new KnowledgeRetrievalTools(knowledge);
``

## 十、第 7 步：注册自定义工具

AgentScope 通过 `@Tool` 和 `@ToolParam` 注解定义工具，通过 `Toolkit` 注册。

### 定义工具类

``java
import io.agentscope.core.tool.Tool;
import io.agentscope.core.tool.ToolParam;

public class WeatherTools {

    @Tool(name = "get_weather", description = "获取指定城市的当前天气信息")
    public String getWeather(
            @ToolParam(name = "city", description = "城市名称，如：北京") String city,
            @ToolParam(name = "unit", description = "温度单位", required = false) String unit) {
        return city + "当前温度 25 度，晴";
    }
}
``

### 注册工具

``java
import io.agentscope.core.tool.Toolkit;

Toolkit toolkit = new Toolkit();
toolkit.registerTool(new WeatherTools());
toolkit.registerTool(ragTools);  // 如果有 RAG 工具
``

### @Tool 注解参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `name` | String | 方法名 | 工具名称（建议 snake_case） |
| `description` | String | 自动生成 | 工具描述，帮助 LLM 决定何时调用 |
| `strict` | boolean | false | 严格模式 |
| `readOnly` | boolean | false | 标记为只读工具 |
| `concurrencySafe` | boolean | true | 是否支持并发调用 |
| `externalTool` | boolean | false | 外部工具 |
| `stateInjected` | boolean | false | 是否注入 AgentState |
| `converter` | Class | DefaultToolResultConverter | 自定义结果转换器 |

### @ToolParam 注解参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `name` | String | **必填** | 参数名称（snake_case） |
| `required` | boolean | true | 是否必填 |
| `description` | String | 空 | 参数描述 |

### 工具执行上下文（注入业务数据）

``java
ToolExecutionContext context = ToolExecutionContext.builder()
        .register(new UserContext("user-123"))
        .build();

@Tool(name = "query", description = "查询数据")
public String query(
        @ToolParam(name = "sql") String sql,
        UserContext ctx  // 自动注入，不需要 @ToolParam
) {
    return "用户 " + ctx.getUserId() + " 的查询结果...";
}
``

## 十二、第 9 步：构建权限上下文

权限系统控制哪些工具可以自动执行，哪些需要用户确认（HITL）。

``java
import io.agentscope.core.permission.*;

PermissionContextState permCtx = PermissionContextState.builder()
        .mode(PermissionMode.DEFAULT)
        .build();

// ALLOW - 只读/安全工具，自动放行
String[] allowTools = {
        "read_file", "grep_files", "glob_files", "list_files",
        "memory_search", "memory_get",
        "session_search", "session_list", "session_history",
        "load_skill_through_path", "todo_write",
        "plan_enter", "plan_exit", "agent_list",
        "task_output", "task_list"
};
for (String tool : allowTools) {
    builder.addAllowRule(tool,
            new PermissionRule(tool, null, PermissionBehavior.ALLOW, "userSettings"));
}

// ASK - 写入/执行工具，需要用户确认
String[] askTools = {
        "write_file", "edit_file", "execute",
        "memory_save", "plan_write",
        "agent_spawn", "agent_send", "agent_generate",
        "skill_manage", "propose_skill",
        "task_cancel", "wait_async_results"
};
for (String tool : askTools) {
    builder.addAskRule(tool,
            new PermissionRule(tool, null, PermissionBehavior.ASK, "userSettings"));
}
``

### 权限模式

| 模式 | 说明 |
|------|------|
| `DEFAULT` | 未命中规则的操作默认需要用户确认 |
| `EXPLORE` | 只读工具自动放行，其他需确认 |
| `ACCEPT_EDITS` | 读写工具自动放行，执行类需确认 |

### 权限行为

| 行为 | 说明 |
|------|------|
| `ALLOW` | 自动放行，无需确认 |
| `ASK` | 暂停执行，等待用户确认 |
| `DENY` | 直接拒绝 |

## 十三、第 10 步：组装 HarnessAgent

`HarnessAgent` 是 AgentScope 的核心入口，通过 Builder 模式组装所有组件：

``java
HarnessAgent agent = HarnessAgent.builder()
        // --- 基础配置 ---
        .name("assistant")
        .sysPrompt(sysPrompt)
        .model(mainModel)
        .workspace(Paths.get(workspace))
        .stateStore(stateStore)
        .filesystem(new LocalFilesystemSpec().mode(LocalFsMode.UNRESTRICTED))
        .toolkit(toolkit)
        .maxIters(maxIters)
        .permissionContext(permCtx)

        // --- Git 技能仓库（可选） ---
        .skillRepository(skillRepo)

        // --- 上下文压缩配置 ---
        .compaction(CompactionConfig.builder()
                .triggerTokens(40000)
                .keepTokens(8000)
                .triggerMessages(80)
                .keepMessages(30)
                .flushBeforeCompact(true)
                .offloadBeforeCompact(true)
                .model(compactionModel)
                .truncateArgs(CompactionConfig.TruncateArgsConfig.builder()
                        .maxArgLength(2000)
                        .truncationText("... [参数过长已截断] ...")
                        .build())
                .build())

        // --- 大工具结果卸载 ---
        .toolResultEviction(ToolResultEvictionConfig.builder()
                .maxResultChars(50000)
                .build())

        // --- 长期记忆 ---
        .memory(MemoryConfig.builder()
                .flushTrigger(MemoryConfig.FlushTrigger.always())
                .build())

        .build();
``

| `.permissionContext()` | PermissionContextState | 权限控制 |
| `.skillRepository()` | AgentSkillRepository | 技能仓库 |
| `.compaction()` | CompactionConfig | 上下文压缩配置 |
| `.toolResultEviction()` | ToolResultEvictionConfig | 工具结果卸载配置 |
| `.memory()` | MemoryConfig | 长期记忆配置 |
| `.generateOptions()` | GenerateOptions | LLM 生成参数 |
| `.modelExecutionConfig()` | ExecutionConfig | 模型调用超时/重试 |

@PostMapping(value = "/chat/stream", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
public Flux<ServerSentEvent<String>> streamChat(@RequestBody ChatRequest req) {
    String sessionId = req.sessionId() != null ? req.sessionId() : "default-session";
    String userId = req.userId() != null ? req.userId() : "user-001";

    RuntimeContext ctx = RuntimeContext.builder()
            .sessionId(sessionId)
            .userId(userId)
            .build();

    UserMessage userMsg = new UserMessage(req.content());

    return agent.streamEvents(userMsg, ctx)
            .subscribeOn(Schedulers.boundedElastic())
            .map(this::toSSE)
            .takeUntil(sse -> {
                String data = sse.data();
                return data != null && data.contains("REQUIRE_USER_CONFIRM");
            })
            .onErrorResume(e -> {
                Map<String, Object> err = new HashMap<>();
                err.put("type", "ERROR");
                err.put("error", e.getMessage() != null ? e.getMessage() : "未知错误");
                return Flux.just(toSseRaw(err));
            });
}

@GetMapping("/chat/history")
public Mono<Map<String, Object>> getHistory(
        @RequestParam String sessionId,
        @RequestParam String userId) {
    return Mono.fromCallable(() -> {
        List<Map<String, Object>> messages = new ArrayList<>();
        Optional<AgentState> stateOpt = stateStore.get(
                userId, sessionId, "agent_state", AgentState.class);
        if (stateOpt.isPresent()) {
            for (Msg msg : stateOpt.get().getContext()) {
                if (msg.getRole() == null) continue;
                String role = msg.getRole().name().toLowerCase();
                if ("system".equals(role)) continue;
                Map<String, Object> msgMap = new HashMap<>();
                msgMap.put("role", role);
                msgMap.put("content", msg.getTextContent());
                msgMap.put("timestamp", msg.getTimestamp());
                msgMap.put("id", msg.getId());
                messages.add(msgMap);
            }
        }
        return Map.of("messages", messages);
    }).subscribeOn(Schedulers.boundedElastic());
}
``

@PostMapping(value = "/chat/confirm", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
public Flux<ServerSentEvent<String>> confirm(@RequestBody ConfirmRequest req) {
    RuntimeContext ctx = RuntimeContext.builder()
            .sessionId(req.sessionId())
            .userId(req.userId())
            .build();

    String resumeText = req.approved()
            ? (req.message() != null ? req.message() : "yes, proceed")
            : (req.message() != null ? req.message() : "no, cancel");

            .subscribeOn(Schedulers.boundedElastic())
            .map(this::toSSE)

                String data = sse.data();
                return data != null && data.contains("REQUIRE_USER_CONFIRM");
            });
}
``

### 事件转换（AgentEvent -> SSE）

``java
private ServerSentEvent<String> toSSE(AgentEvent event) {
    Map<String, Object> map = new HashMap<>();
    map.put("type", event.getType().name());

    switch (event.getType()) {
        case TEXT_BLOCK_DELTA ->
                map.put("delta", ((TextBlockDeltaEvent) event).getDelta());
        case THINKING_BLOCK_DELTA ->
                map.put("delta", ((ThinkingBlockDeltaEvent) event).getDelta());
        case TOOL_CALL_START -> {
            ToolCallStartEvent e = (ToolCallStartEvent) event;
            map.put("toolCallName", e.getToolCallName());
            map.put("toolCallId", e.getToolCallId());
        }
        case TOOL_CALL_END -> { }
        case TOOL_RESULT_TEXT_DELTA -> {
            ToolResultTextDeltaEvent e = (ToolResultTextDeltaEvent) event;
            map.put("toolCallId", e.getToolCallId());
            map.put("delta", e.getDelta());
        }
        case REQUIRE_USER_CONFIRM -> {
            RequireUserConfirmEvent e = (RequireUserConfirmEvent) event;
            map.put("replyId", e.getReplyId());
            List<Map<String, Object>> toolCalls = new ArrayList<>();
            for (ToolUseBlock tb : e.getToolCalls()) {
                toolCalls.add(Map.of("id", tb.getId(), "name", tb.getName(), "input", tb.getInput()));
            }
            map.put("toolCalls", toolCalls);
        }
        default -> { }
    }
    return toSseRaw(map);
}
``

### SSE 事件类型

| 事件类型 | 数据字段 | 说明 |
|----------|----------|------|
| `TEXT_BLOCK_DELTA` | `delta` | Agent 生成的文本增量 |
| `THINKING_BLOCK_DELTA` | `delta` | Agent 思考过程增量 |
| `TOOL_CALL_START` | `toolCallName`, `toolCallId` | 工具调用开始 |
| `TOOL_CALL_END` | - | 工具调用结束 |
| `TOOL_RESULT_TEXT_DELTA` | `toolCallId`, `delta` | 工具返回结果增量 |
| `REQUIRE_USER_CONFIRM` | `replyId`, `toolCalls` | 需要用户确认（HITL） |
| `AGENT_START` / `AGENT_END` | - | Agent 推理开始/结束 |
| `MODEL_CALL_START` / `MODEL_CALL_END` | - | 模型调用开始/结束 |
| `ERROR` | `error` | 错误信息 |

## 十五、第 12 步：前端 SSE 对接

前端通过 fetch 读取 SSE 流，根据 `type` 字段渲染不同 UI：

``typescript
const response = await fetch('/api/chat/stream', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ content: '你好', sessionId: 'session-1', userId: 'user-1' })
});

const reader = response.body!.getReader();
const decoder = new TextDecoder();

while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    const text = decoder.decode(value);
    const lines = text.split('\n').filter(l => l.startsWith('data:'));

    for (const line of lines) {
        const data = JSON.parse(line.replace('data:', '').trim());

        switch (data.type) {
            case 'TEXT_BLOCK_DELTA':
                appendText(data.delta);
                break;
            case 'THINKING_BLOCK_DELTA':
                appendThinking(data.delta);
                break;
            case 'TOOL_CALL_START':
                showToolCall(data.toolCallName, data.toolCallId);
                break;
            case 'TOOL_RESULT_TEXT_DELTA':
                appendToolResult(data.toolCallId, data.delta);
                break;
            case 'REQUIRE_USER_CONFIRM':
                showConfirmDialog(data.toolCalls, data.replyId);
                break;
            case 'ERROR':
                showError(data.error);
                break;
        }
    }
}

## 十六、核心概念详解

### 16.1 ReAct 推理循环

AgentScope 的核心推理模式是 **ReAct**（Reasoning + Acting）：

``
用户输入 -> 模型推理 -> 是否调用工具？
                        |-- 是 -> 执行工具 -> 将结果反馈给模型 -> 继续推理
                        +-- 否 -> 输出最终回复
``

`maxIters` 控制最大循环次数，防止无限推理。

### 16.2 上下文压缩（Compaction）

当对话过长时自动触发压缩，防止超出模型 token 上限：

``
对话 token 数 >= triggerTokens（40K）
    |
1. flushBeforeCompact: 将重要信息写入长期记忆
2. offloadBeforeCompact: 将原始日志卸载到文件
3. 调用 compactionModel 生成摘要
4. 保留最近 keepTokens（8K）/ keepMessages（30）条原文
``

### 16.3 工具结果卸载（Tool Result Eviction）

当工具返回结果过大时（> 50K 字符），将完整结果写入文件，上下文中只保留摘要 + 文件引用。

### 16.4 长期记忆（Memory）

Agent 可以在对话中记住重要信息，跨会话持久化。配置 `flushTrigger` 控制刷新时机：
- `always()` - 每次对话后都刷新
- `never()` - 不自动刷新

### 16.5 权限系统（HITL）

当 Agent 调用需要确认的工具时：
1. Agent 暂停执行
2. 发送 `REQUIRE_USER_CONFIRM` 事件
3. SSE 流结束
4. 前端展示确认对话框
5. 用户决策后调用 `/api/chat/confirm` 恢复执行

### 16.6 多租户隔离

`HarnessAgent` 是无状态的单例，通过 `RuntimeContext` 的 `(userId, sessionId)` 隔离不同用户的会话状态。同一 session 的请求自动串行，不同 session 可并行。

## 十九、常见问题

### Q1: 如何切换模型？

修改 `application.yaml` 中的 `agent.model.*` 配置即可。AgentScope 兼容所有 OpenAI 协议的模型服务（OpenAI、DeepSeek、通义千问、vLLM 等）。

### Q2: 如何添加自定义工具？

1. 创建工具类，使用 `@Tool` 和 `@ToolParam` 注解标记方法和参数
2. 在 `ChatController` 构造函数中通过 `toolkit.registerTool(new YourTools())` 注册
3. 在权限配置中添加对应的 ALLOW/ASK 规则

### Q3: 如何禁用某些内置工具？

使用 Builder 的 disable 方法：
``java
HarnessAgent.builder()
        .disableFilesystemTools()   // 禁用文件系统工具
        .disableShellTool()         // 禁用 Shell 工具
        .disableMemoryTools()       // 禁用记忆工具
        ...
``

### Q4: 如何处理长对话？

框架内置了上下文压缩机制，配置 `agent.compaction.*` 即可自动触发。建议：
- `triggerTokens` 设为模型上下文窗口的 50%-70%
- `keepTokens` 设为模型上下文窗口的 10%-20%
- 开启 `flushBeforeCompact` 保存重要信息到长期记忆

### Q5: 如何部署到生产环境？

1. 使用 MySQL 作为会话状态存储（`agentscope-extensions-mysql`）
2. 使用外部向量库（PgVector / Milvus）替代内存向量库
3. 配置 `LocalFsMode.WORKSPACE_ONLY` 限制文件访问范围
4. 设置合理的权限规则
5. 配置 HTTPS 和认证

### Q6: 如何实现多 Agent 协作？

使用 `HarnessAgent` 的子 Agent 功能：
``java
HarnessAgent.builder()
        .subagent(SubagentDeclaration.builder()
                .agentId("researcher")
                .name("Researcher")
                .sysPrompt("你是一个研究员...")
                .build())
        .build();
``

Agent 可以通过 `agent_spawn`、`agent_send` 等工具与子 Agent 交互。

### Q7: 如何接入 MCP 服务器？

AgentScope 支持 MCP（Model Context Protocol）协议，可以在 `tools.json` 中配置 MCP 服务器，或通过 `Toolkit` 注册 MCP 客户端。
